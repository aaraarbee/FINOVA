# Finova

Modern Financial Analytics Platform built using:

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Chart.js
- Bootstrap 5

---

- User Signup
- User Login

- Secure Firebase Authentication
- Logout System

- Financial Overview

- Budget Usage
- Interactive Charts

- Firebase Firestore Storage
- Dynamic Transaction Table

# Firebase Setup

## 1. Create Firebase Project

Go to:
https://console.firebase.google.com

---

## 2. Enable Authentication

Authentication
→ Email/Password
→ Enable

---

## 3. Enable Firestore Database

Firestore Database
→ Create Database
→ Start in Test Mode
